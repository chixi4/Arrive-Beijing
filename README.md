# 到站北京

「**京通**」App 中「到站北京」模块的高保真可交互移动端原型，由设计稿（PDF + 导出截图）重建为纯前端实现，无任何框架依赖。

> 入口路径：京通首页 → 全部服务 → **到站北京（旅客端）** / **短途复载（司机端）**

## 项目背景

「到站北京」是京通平台下面向北京铁路与机场枢纽的出行服务模块，覆盖旅客与出租车司机两类用户。本项目以官方设计稿为事实源，将其重建为可点击、可走通完整流程的静态移动端原型，用于交互验证与演示。

原始输入为一份设计 PDF、48 张导出界面截图和 10 个站点图标；产出为一套可在手机屏幕上完整体验的前端原型。

## 功能模块

### 旅客端

- **站区首页** — 站点切换、快捷服务宫格、站区公告入口
- **导航指引** — 平面地图 / 3D 总览 / AR 实景导航 / 路线规划（B1/F1/F2/F3 楼层可切换）
- **交通接驳** — 出租车 / 网约车 / 地铁 / 公交 / 综合推荐 / 其他交通
- **场站换乘** — 以北京南站为起点，可选其余 9 个火车站 / 机场，给出地铁、出租、网约、公交方案
- **停车指引** — 停车场列表与分时段、分车型收费对比
- **站区公告** — 全部 / 紧急 / 通知 / 提示 / 活动分类筛选，公告详情
- **全部服务** — 站内引导、问询服务（服务热线、投诉举报、监督邮箱）、投诉建议（含图片上传）、我的反馈
- **旅客设置** — 个人资料与偏好

### 司机端

- **排队情况** — 各站区实时排队数据，分区域查看
- **场站详情** — 场站地图、排队统计、调度信息
- **短途复载** — 站点选择 → 区域选择 → 派单选择 三级流程；历史订单与积分
- **的士之家** — 资讯、餐饮、积分兑换
- **个人中心** — 司机资料与运营数据

### 通用能力

- 基于 `location.hash` 的自研 SPA 路由，47 个页面路由全部可达
- 站点切换轮播 + `localStorage` 状态持久化，换站后首页站名动态更新
- 路由级关键图片预加载与下一路由预取
- Toast 提示、可选中反馈（楼层、公告分类、反馈类型、预约时段等）
- 桌面端预览缩放适配

## 构建过程

项目按四个阶段推进，每个阶段都有对应的文档沉淀（见 `docs/`）与验证手段。

**1 · 骨架与内容事实**
先建页面地图（`docs/page-map.md`）和内容清单（`docs/content-inventory.md`），文案全部以导出截图为事实源、人工读图整理，**不使用 OCR 或位图自动识别**，以保证站名、标签、文案丝毫不差。先用「截图保真页 + 透明点击热区」跑通完整点击层级，再把高价值页面逐步迁移为真实 HTML 组件。

**2 · 设计系统与组件库**
从代表性锚点页抽取语义化设计 token（`--ds-*`：颜色、字阶、圆角、间距、阴影），沉淀可复用组件（`topbar` / `bottom-nav` / `card` / `chip` / `ab-page` / `ab-select-grid` 等），并提供 `#/design-system` 预览页作为 QA 面板，使视觉问题可以在系统层统一修复。

**3 · 图标系统**
90 个图标按 3×3 批次系统化生产，统一转换为 `currentColor` 的内联 SVG（页面通过 CSS 控制颜色），并做像素级校准与语义核对（如 `map`/`route`/`navigation`、`parking`/`car` 严格区分），避免逐页手绘导致的图标漂移。

**4 · 图片资源**
站点建筑图、导航 / 交通 / 停车示意图、开屏主视觉等按真实页面断点裁切适配竖屏 / 横屏位置，原始图片保留以便后续重新裁切。

> 实现过程中根据指导教师在 5/27 追加的需求，补充了站内服务、问询服务、场站换乘（10 条线路）等页面。

## 技术实现

| 指标 | 数据 |
|------|------|
| 技术栈 | 原生 HTML + CSS + JavaScript，零框架依赖 |
| JavaScript | ~5,100 行，含 80 个渲染函数 |
| CSS | ~9,500 行，全手写样式 + 设计 token |
| SVG 图标 | 90 个，`currentColor` 内联，像素级校准 |
| 路由 | 基于 hash 的自研 SPA 路由，47 个路由可达 |
| 状态 | `localStorage` 持久化当前站点 |
| 验证 | Chrome headless / CDP 自动核查路由可达性与资源加载 |

## 本地运行

纯静态文件，任意 HTTP 服务器即可：

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```

浏览器打开 `http://localhost:8000`，建议使用手机屏幕尺寸（约 390×844）查看最佳效果。

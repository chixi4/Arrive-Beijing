# Page Spec

本文件记录当前静态原型的页面事实源、交互要求和后续重构约束。当前阶段以页面完整、文字准确、点击层级准确为第一优先级。

## 实现原则

- 除明确需要改交互的页面外，页面正文直接使用 `extracted_screenshots/` 中的导出截图作为事实源，避免手工重写造成漏字、错字。
- 禁止使用 OCR、位图转 CSV、位图自动识别工具提取文案。后续真实 HTML 化时，只能人工视觉读图整理文字。
- `#/station/select` 和 `#/station/switch` 是自定义 HTML 页面，复用 `extracted_page04_station_icons/` 的 10 个站点图标。
- `#/feedback/submit-more` 保留截图文字，但上传图片区按用户要求简化为 1 个“添加”入口。
- 司机端上层入口 `#/driver/splash` 点击后进入 `#/driver/short-haul/booking`，与首页第 8 个“短途复载”入口效果一致。

## 截图覆盖

- 原始导出截图共 48 张。
- 当前路由直接使用 44 张截图。
- 4 张站区切换截图未直接使用：`P04-02_站区切换页.png`、`P05-02_站区切换页.png`、`P06-01_站区切换页.png`、`P06-02_站区切换页.png`。原因是站点选择/切换已按用户要求改为自定义交互页。
- 当前路由数量：47 个，包括 45 个截图路由和 2 个自定义站点路由。

## 本轮验证记录

- 使用 Chrome headless/CDP 核查所有页面路由，45 个截图路由图片均加载完成。
- 自定义站点页核查通过：`#/station/select` 与 `#/station/switch` 均有 10 个站点按钮和 1 个确认按钮。
- 链接关系核查通过：47 个 `data-to` 目标均存在，没有死链。
- 站区切换核查通过：清空本地存储后默认北京西站，点击北京南站后当前选中变为北京南站，确认后进入 `#/station/home` 并写入 `arrive-beijing.station=south`。

## 后续真实 HTML 重构提醒

- 先按本文件和 `docs/page-map.md` 建组件，不要直接按视觉喜好删页面或删文案。
- 每个页面真实 HTML 化前，必须对照原截图人工视觉读图确认中文文字。
- 如果某个页面只是上一页滚动后的状态，也要保留为独立可达状态，不能合并到无法到达的滚动区域里。

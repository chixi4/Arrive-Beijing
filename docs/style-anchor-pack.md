## 生成原则

- 只用文字，不上传参考图。
- 同一套视觉语言：白底、浅灰背景、蓝色主色、1px 分隔、8-12px 圆角、轻阴影。
- 文案尽量使用项目中的真实中文词条。
- UI 要像真实上线产品，不要像概念稿、海报或营销页。

## Prompt 迭代记录

- 首页初稿偏彩色，卡片和图标有点像应用商店首页。
- 第二轮把主色、图标风格、底栏文案和卡片密度都收紧，最终采用第二版。
- 车站排队页初稿在后半部分出现了空站名。
- 第二轮把 10 个站点名称写死后，列表完整可读，最终采用第二版。

## 设计判断

- 保留原稿的信息层级：入口页 -> 旅客端/司机端 -> 站点选择 -> 各服务页。
- 重构视觉语言：用更克制的政务交通服务风格替代原图的大渐变、大阴影、大圆角和松散卡片。
- 旅客端主色使用蓝色，司机端保留绿色/蓝色区分，但全局组件密度、圆角、阴影保持一致。
- 后续真正做视觉重构时，先以当前截图热区原型校准页面和文案，再替换为设计系统组件，不能直接凭记忆重写文案。

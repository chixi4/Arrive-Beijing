# Requirements Checklist

本清单用于每轮实现后的自查。当前阶段的最高优先级是页面完整、文字准确、点击层级准确。

## 全局硬性要求

- [x] 项目在 `Arrive-Beijing` 目录内初始化 git。
- [x] 实现方式为纯 HTML/CSS/JS 静态原型。
- [x] 页面展示为手机尺寸移动端界面。
- [x] 不使用 OCR、位图转 CSV、位图自动识别工具提取文案。
- [x] 站点图标复用 `extracted_page04_station_icons/`。
- [x] 页面文字当前以导出截图为事实源，避免人工重写导致错字漏字。
- [x] 不接真实数据，不做真实表单提交。
- [x] 已建立 `docs/page-spec.md` 记录页面事实源、自定义页面和互动细节。
- [x] 已建立全局设计系统 token 与组件库预览页，可用于后续新页面复用。
